## The word

**THINGAMAJIG** — the word a grandma texts about AI.

When a grandchild shows her a chatbot, a robot vacuum or a smart
speaker, she does not learn its brand name — she points at it and
calls it "that thingamajig". One word, warm and baffled, tied to
the machine in front of her, and funny with no caption at all: the
joke is that every new AI gadget in the world ends up with the same
name in her texts.

## How it works

`main.ts` (Node 22, standard library only, no network, no clock,
no randomness) writes exactly `THINGAMAJIG` to `/output/entry.txt` —
11 characters, 11 bytes, a single word inside the 1–30 character gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
